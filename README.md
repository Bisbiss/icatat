# Icatat - Pencatatan Keuangan Cepat & Simpel

**Icatat** adalah aplikasi pencatatan keuangan pribadi modern berbasis React & Vite yang berfokus pada kecepatan input, kesederhanaan, dan responsivitas penuh di perangkat mobile (mengubah navbar menjadi slide-out drawer).

---

## Fitur Utama

- 📱 **Mobile Responsive with Drawer Navigation**: Pada layar mobile (< 768px), navbar bertransformasi menjadi slide-out drawer yang praktis dan elegan.
- ⚡ **Input Super Cepat**: Modal input dengan tombol shortcut nominal (+10rb, +25rb, +50rb, +100rb, +500rb) dan pemilih kategori berkode warna.
- 💰 **Ringkasan Keuangan Instan**: Menampilkan Saldo Utama, Total Pemasukan, dan Total Pengeluaran secara real-time.
- 📊 **Analisis Kategori Visual**: Visualisasi persentase pengeluaran & sumber pemasukan dengan progress bar serta indikator rasio tabungan (*savings rate*).
- 🔍 **Filter & Pencarian**: Filter berdasarkan waktu (Semua, Bulan Ini, Hari Ini), tipe (Semua, Keluar, Masuk), dan pencarian instan.
- 💾 **Penyimpanan Lokal (LocalStorage)**: Data tersimpan otomatis di browser tanpa perlu registrasi atau login.
- 🌓 **Mode Gelap / Terang**: Dukungan toggle tema gelap dan terang dengan kontras modern.
- 📥 **Ekspor CSV**: Kemudahan mengunduh rekap riwayat transaksi ke format file Excel / CSV.

---

## Cara Menjalankan

1. **Jalankan Development Server**:
   ```bash
   npm run dev
   ```

2. Buka URL yang muncul di terminal (biasanya `http://localhost:5173`) di browser Anda.

3. **Build untuk Produksi**:
   ```bash
   npm run build
   ```
